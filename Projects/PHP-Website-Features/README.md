# PHP Website Features — CV Upload

## Problem addressed
The website needed a way for users to upload CV documents, with checks to prevent unsupported or oversized files and clearer feedback when an upload did not meet the requirements.

## My contribution
I examined the existing PHP project and worked on CV upload functionality, file handling, upload validation and error handling. I then added file-type and file-size restrictions and used conditional checks to display appropriate error messages.

## Technologies
PHP, file handling, conditional logic, upload validation and error handling. Laravel was researched as part of preparation for the website development work.

## Result
The WIL logbook records initial CV upload functionality and subsequent improvements to validation and error handling.
