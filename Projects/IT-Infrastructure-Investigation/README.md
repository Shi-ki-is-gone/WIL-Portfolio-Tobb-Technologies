# IT Infrastructure Investigation

## Problem addressed
The workplace needed an investigation into computer performance and reliability, covering hardware, operating system, software and network factors.

## My contribution
I used command-line tools to inspect CPU, RAM and storage information, physically inspected hardware, ran Ubuntu/Linux diagnostics and carried out network speed and system checks. I documented findings and compiled them into a technical report using GitHub Markdown.

## Technologies and tools
Ubuntu, Linux command line, hardware inspection, system diagnostics, network speed testing, GitHub and Markdown.

## Result
The logbook records RAM and slow internet connectivity as factors affecting system performance. Findings were compiled into a report with supporting evidence.
